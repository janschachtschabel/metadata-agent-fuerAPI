📚 Metadata Agent Canvas - Bookmarklet

Ziehe den folgenden Button in deine Lesezeichen-Leiste:

📝 Metadata Agent

📖 Anleitung

  1. Ziehe den Button "📝 Metadata Agent" in deine Lesezeichen-Leiste
  2. Besuche eine beliebige Webseite
  3. Klicke auf das Lesezeichen
  4. Das Metadata-Formular öffnet sich als Sidebar
  5. Gib eine Beschreibung ein oder wähle eine Inhaltsart
  6. Die KI extrahiert automatisch Metadaten
